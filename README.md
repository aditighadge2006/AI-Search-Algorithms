# AI Search Algorithms

## Practical: Problem Solving Through Search

This repository contains the implementation of various problem-solving search algorithms using Python.

## Algorithms Implemented

1. Breadth First Search (BFS)
2. Depth First Search (DFS)
3. A* Search
4. Best First Search
5. Hill Climbing
6. Constraint Satisfaction Problem (Map Coloring)

## Categories

- Uninformed Search: BFS, DFS
- Informed Search: A*, Best First Search
- Local Search: Hill Climbing
- Constraint Satisfaction: Map Coloring

## Tools Used

- Python
- Google Colab
- GitHub

## Description

The algorithms were implemented and tested to understand different search strategies and compare their characteristics, advantages, and limitations.
